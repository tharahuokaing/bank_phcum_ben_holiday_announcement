# bank_holiday_announcement
# 🏦 HUOKAING THARA BANK - Pchum Ben Holiday Notice

A professional, bilingual (Khmer & English) official holiday announcement web page designed for **HUOKAING THARA BANK**, noting the official closure for the Pchum Ben Festival from **08 October 2026 to 13 October 2026**.

## 🌟 Features / លក្ខណៈពិសេស
* **Bilingual Support:** Full content provided in both Khmer (ភាសាខ្មែរ) and English.
* **Modern & Traditional Aesthetic:** Styled with a luxurious dark theme, gold borders (`#d4af37`), and a rich wooden texture card design.
* **Responsive Layout:** Optimized for both desktop displays and mobile devices.
* **Clean Structure:** Separated code structure with independent HTML, CSS, and JavaScript files.

## 📅 Holiday Schedule / កាលបរិច្ឆេទឈប់សម្រាក
* **Not Working From / មិនធ្វើការចាប់ពី:** 08 October 2026 (ថ្ងៃទី ០៨ តុលា ២០២៦)
* **To / ដល់ថ្ងៃទី:** 13 October 2026 (ថ្ងៃទី ១៣ តុលា ២០២៦)
* **Resume Normal Operations / ចូលធ្វើការធម្មតាវិញ:** 14 October 2026

## 📁 Project Structure / រចនាសម្ព័ន្ធថតឯកសារ
```text

## 🚀 Getting Started / វិធីប្រើប្រាស់

1. Clone or download this repository to your local machine.
2. Ensure all files (`index.html`, `style.css`, `script.js`, and `bank.jpg`) are in the same root directory.
3. Open `index.html` in any modern web browser or deploy it directly via **GitHub Pages**.
